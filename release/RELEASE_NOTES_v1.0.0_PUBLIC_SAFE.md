# CORE-LLM-Bench v1.0.0 public-safe fallback note (draft)

The paper evaluates Family, Pizza 100, Pizza 250, and OWL2Bench. This fallback
distribution contains only Pizza 100, Pizza 250, and OWL2Bench: 5,272 unique
question-hop instances (3,455 BQA and 1,817 OEQA). It excludes every
Family/FHKB source and derived benchmark payload as an optional reduced
profile.

This is a contingency package, not the intended canonical v1.0.0 release. See
`docs/FAMILY_RECONSTRUCTION.md` for the qualified local reconstruction path.
The canonical full v1.0.0 benchmark is archived at
https://zenodo.org/records/22742977 under DOI `10.5281/zenodo.22742977`; its
canonical tabular 9,032-row dataset view is available at
https://huggingface.co/datasets/jloe2911/CORE-LLM-Bench, and its
source release is available at
https://github.com/jloe2911/CORE-LLM-Bench/releases/tag/v1.0.0.
